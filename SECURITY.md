# Security

This is a research preview. Prefer static browser execution for public demonstrations. The native API limits request size and simulation dimensions but is not a hardened multi-tenant compute service.

Do not post secrets or exploit details in public issues. If GitHub private vulnerability reporting is enabled, use the repository Security tab. Otherwise contact the maintainer through a private channel already known to you, or use GitHub's abuse reporting for platform issues. No unverified email address is published here.

Review dependencies and permissions before distributing a release. Desktop builds run only the bundled Python sidecar and do not accept arbitrary command names from the UI.
