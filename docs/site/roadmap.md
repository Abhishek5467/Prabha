# Roadmap

## v0.1 preview: freeze the validated ANN prototype

Deliver a usable Studio, shared Python operations, original designer access, evidence archive, documentation and reproducible packaging. Treat installer validation, public hosting configuration, accessibility feedback and release review as launch gates.

## Next scientific milestone: B25

Implement a convolution primitive only after freezing the ANN baseline. Start with an analytical discrete convolution reference, explicit padding/stride/kernel definitions, converter-aware physical mapping and small deterministic fixtures. Then study precision and noise.

## Later work

- Integrate noisy receiver physics into multi-layer inference with explicit timing.
- Calibrate against measured hardware; record uncertainty and model provenance.
- Extend spec conformance coverage to the later standalone components.
- Evaluate token-oriented optical acceleration with complete conversion, memory, weight-setting and control costs.

The LLM paper draft is an architecture and evaluation proposal. No LLM benchmark or accelerator speed/energy result has been measured in the current repository.
