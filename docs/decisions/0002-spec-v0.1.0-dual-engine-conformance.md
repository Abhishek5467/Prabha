# ADR-0002: Milestone — spec v0.1.0, two conformant engines

Date: 2026-07-13
Status: Accepted (milestone record)

## Context
Prabha's core bet: a language-neutral spec (5 JSON schemas + 18 semantic rules
+ 14 conformance fixtures) as the single source of truth, with engines as
replaceable implementations.

## Decision / Record
As of this date, BOTH engines pass 14/14 conformance against identical fixture
files on the development machine (Windows, MSVC 19.51 x64 / Python 3.12):
- core-py  (reference/oracle): golden PEMAN z=0.6384 vs analytic 0.6388
- core-cpp (performance):      exact fixtures to 1e-9, noise statistics in
  bounds with a different RNG (mt19937_64 vs PCG64) — validating the
  exact/stats split in the conformance policy.
Noise seeding is cross-language deterministic: CRC32(instance_id)+run_seed.

## Known gaps (tracked)
- R6 (domain-match) has no fixture until a frequency-domain block exists.
- core-cpp Phase 0 is minimal (no full JSON-Schema validation; valijson later).
- core-cpp performance ~ parity with numpy at PEMAN scale; M3 optimization
  runway documented (SIMD, RNG, fused kernels, threading).
